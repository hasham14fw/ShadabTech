# Shadab Technologies Web Platform

Modern, responsive corporate web platform for **Shadab Technologies** — an enterprise software engineering, cloud architecture, and cognitive AI solutions provider.

Built with **React (Vite)**, **HTML5 Canvas**, **Vanilla CSS**, **React Router**, and **Lucide Icons**.

---

## 🚀 Key Features

- **Geometric Vector Logo & Brand Identity**: Custom vector SVG monogram emblem featuring cyan and royal blue circuitry conduits.
- **Interactive Canvas Network Simulation**: High-performance 60 FPS HTML5 canvas network background with floating nodes, data packet pulses, and magnetic cursor attraction.
- **Dynamic Animated Typewriter Headline**: Cycling headline showcasing expertise in Digital Intelligence, MERN Web Apps, Cognitive AI, Zero-Trust, and Microservices.
- **3D Hover & Tap Capability Cards**: 3D perspective flip cards with front specifications and back architectural breakdowns. Optimized with Chromium-proof hardware acceleration and mobile tap support.
- **Alternating Services Showcase**: 2-part alternating layout with dedicated service cards and technical deliverables checklists.
- **Interactive Project Estimator**: Real-time project sprint scope and architecture duration calculator.
- **Interactive Proposal Form**: Direct contact channels with real-time validation and celebratory submission effects.
- **Ultra-Responsive**: Mobile-first design architecture tested on screens from 320px to 4K displays.

---

## 🛠️ Technology Stack

- **Frontend**: React 18, Vite
- **Routing**: React Router DOM v6
- **Graphics & Icons**: HTML5 Canvas, Lucide React, Custom SVG
- **Styling**: Vanilla CSS Design Tokens (Glassmorphism, 3D CSS Transforms, Modern Blue & White Palette)
- **Effects**: Canvas-Confetti

## 💻 Local Development

```bash
# Clone the repository
git clone https://github.com/hasham14fw/ShadabTech.git

# Navigate into project directory
cd ShadabTech

# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
